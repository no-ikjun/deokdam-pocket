# 덕담 주머니: 2027 정미년, 나는 어떤 양?

연말연시 질문 12개로 나의 양 유형과 2027년 운세를 알려주는 새해 놀이 서비스입니다.
로그인 없이 테스트하고, 결과를 스토리에 올리고, 친구와 궁합을 보고, 단톡방 양 무리를 만들 수 있어요.

## 기능

| 기능 | 주소 | 설명 |
| --- | --- | --- |
| 유형 테스트 | `/`, `/test` | 12문항, 에너지 2 × 계획 2 × 관계 3 = 12가지 양 |
| 결과 카드 | `/result/[유형]` | 한 줄 요약, 운세, 행운의 달·아이템·장소, 덕담, 찰떡궁합·상극 |
| 공유 이미지 | `/result/[유형]/image/story`, `/image/og` | 9:16 스토리 이미지와 링크 미리보기 |
| 궁합 | `/pair/[결과 번호]`, `/pair/r/[궁합 번호]` | 링크를 받은 친구가 테스트하면 둘의 궁합(78쌍) |
| 양 무리 | `/flock/[무리 번호]` | 단톡방·가족 무리, 역할 배정과 무리 운세 |
| 오늘의 복주머니 | `/daily` | 12/15~설날, 하루 한 번 카드 150장 중 하나. 도감 |
| 지난 시즌 | `/classic`, `/social`, `/pocket`, `/self` | 2026년까지의 덕담 주머니와 AI 자기 대화 |

카카오 로그인은 선택입니다. 로그인하면 복주머니 도감이 계정에 남고 1년 뒤 알림을 신청할 수 있어요.

## 구조

```
src/config/season.ts        연도, 간지, 오픈일, 설날. 해가 바뀌면 여기만 고친다
src/sheep/data/             문구와 데이터: 유형, 질문, 결과 문구, 궁합 78쌍, 카드 150장
src/sheep/                  규칙: 점수 계산, 궁합 점수, 무리 역할·운세, 임시 양 그림
src/sheep/server/           서버 전용: 익명 식별자, DB 조회, 복주머니 날짜
src/app/(sheep)/            새 서비스 화면
src/app/(legacy)/           지난 시즌 화면 (주소는 그대로)
src/app/api/sheep/          새 서비스 API
db/migrations/              새 테이블 SQL (번호 순서대로 적용)
scripts/check-sheep.ts      문구·규칙 자동 점검
```

문구는 모두 미리 써둔 정적 콘텐츠이고, 운영 중 AI를 호출하지 않습니다.
문구를 고친 뒤에는 점검을 돌려 빠진 쌍이나 겹치는 이름이 없는지 확인하세요.

```bash
npm run check:sheep
```

### 환경변수

| 이름 | 용도 |
| --- | --- |
| `POSTGRES_URL` 등 | Vercel Postgres. 결과 저장, 궁합, 무리, 복주머니에 필요 |
| `JWT_SECRET` | 로그인 쿠키 서명 |
| `NEXT_PUBLIC_SERVICE_URL` | 카카오 로그인 후 돌아올 주소의 앞부분 |
| `NEXT_PUBLIC_KAKAO_REST_API_KEY` | 카카오 로그인 |
| `NEXT_PUBLIC_KAKAO_JS_KEY` | 카카오톡 공유 버튼. 없으면 버튼이 숨겨진다 |
| `SHEEP_TEST_DATE` | 복주머니의 "오늘"을 `YYYY-MM-DD`로 고정. 오픈 전 점검용이며 운영에는 넣지 않는다 |

DB 없이도 테스트와 결과 카드, 공유 이미지는 동작합니다(결과가 브라우저에만 남아요).

### 캐릭터 일러스트 교체

지금 양 그림은 `src/sheep/art.ts`가 코드로 그리는 임시 그림입니다(몸은 같고 목도리 색만 다름).
일러스트 12종이 준비되면 이 파일의 `sheepDataUri`가 유형별 이미지 주소를 돌려주도록 바꾸면
화면과 공유 이미지에 함께 반영됩니다.
